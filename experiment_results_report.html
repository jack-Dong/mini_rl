Score Centering (arXiv:2609.20807) · Qwen3-0.6B Countdown 实时复现实验报告

在受控权重噪声 TIM、真实 vLLM 推理引擎（PagedAttention + FlashInfer） 异步采样、以及硬件级 FP8 量化三种训推不匹配机制下， 全面对比原生 PG、朴素 IS、截断 TIS 与论文提出的 TIS + Top-k 得分中心化（k=128） 的收敛精度与稳定性。

基座模型：Qwen/Qwen3-0.6B 任务环境：3 操作数 Countdown（1..25 → 1..200） 核心损失：-A [w(r_tok) log p_tok - Σ_{j∈Top-k} (q_j w(r_j) - α p_j) log p_j]

核心结论与实时实验分析（Key Findings）

方法设计：在训推不匹配（Training-Inference Mismatch, TIM）场景下，直接对采样序列做强化学习更新（Vanilla PG）会因分布偏移积累偏差； 朴素重要性采样（IS）无偏但易受极端比率尾部冲击；截断重要性采样（TIS）抑制高方差尾部但会引入截断偏差。 Score Centering 在 Top-k 词汇子集（k=128）上利用自适应质量对齐基线中心化词表梯度，在真实 vLLM V1 引擎中检验其无偏性与梯度稳定性表现。

  • 实验一 · 受控权重噪声 TIM（Controlled Weight-Noise TIM）（已完成）：PG 末期=28.1%（峰值 37.5%，均梯度 14.56 / 末步 32.86，均 |KL|=0.0252）；IS 末期=35.9%（峰值 39.1%，均梯度 6.71 / 末步 6.75，均 |KL|=0.0101）；TIS 末期=35.9%（峰值 39.1%，均梯度 9.06 / 末步 18.98，均 |KL|=0.0141）；TIS+SC 末期=35.9%（峰值 35.9%，均梯度 10.50 / 末步 13.75，均 |KL|=0.0187）；对比结论：末期最高精度 IS (35.9%，相对 PG +7.8 pp)，全程最小平均梯度范数 IS (6.71)。
  • 实验二 · 真实 vLLM 推理引擎 TIM（PagedAttention + FlashInfer）（已完成）：PG 末期=35.9%（峰值 43.8%，均梯度 7.26 / 末步 11.07，均 |KL|=0.0140）；IS 末期=50.0%（峰值 51.6%，均梯度 9.50 / 末步 9.91，均 |KL|=0.0131）；TIS 末期=45.3%（峰值 46.9%，均梯度 8.12 / 末步 8.28，均 |KL|=0.0152）；TIS+SC 末期=37.5%（峰值 42.2%，均梯度 7.39 / 末步 6.83，均 |KL|=0.0130）；对比结论：末期最高精度 IS (50.0%，相对 PG +14.1 pp)，全程最小平均梯度范数 PG (7.26)。
  • 实验三 · 硬件级 FP8 (E4M3FN) 权重量化 + vLLM 异步采样 TIM（已完成）：PG 末期=26.6%（峰值 40.6%，均梯度 19.36 / 末步 51.83，均 |KL|=0.1854）；IS 末期=34.4%（峰值 40.6%，均梯度 8.88 / 末步 26.82，均 |KL|=0.1064）；TIS 末期=40.6%（峰值 40.6%，均梯度 6.55 / 末步 4.49，均 |KL|=0.1225）；TIS+SC 末期=31.2%（峰值 37.5%，均梯度 4.89 / 末步 2.08，均 |KL|=0.1172）；对比结论：末期最高精度 TIS (40.6%，相对 PG +14.1 pp)，全程最小平均梯度范数 TIS+SC (4.89)。
  • 跨实验总体规律（80 步真实 vLLM 复现）：① 在全部 3 种 TIM 机制（受控权重噪声、FP16 vLLM+FlashInfer、FP8 E4M3FN 量化）中，从 17.2% 零步基线出发，带重要性校正的方法（IS / TIS / TIS+SC）在第 79 步评估准确率均一致超越原生 PG；② 当漂移增强（尤其是实验三 FP8 量化下朴素 IS 全程最大 IS 比率飙升至 205.79x、第 79 步仍达 24.41x）时，PG 与朴素 IS 的末步梯度范数剧烈飙升（分别达 51.83 与 26.82），而截断类的 TIS（末期 40.6% 最高、末步梯度 4.49）与 TIS+SC（末步梯度 2.08、均梯度 4.89 全场最低）显著抑制了方差冲击；③ 在当前 80 步 / Top-k=128 小批量条件下，TIS+SC 的头质量自适应残差表现出最稳健的梯度平滑性，但在轻中度漂移下的末期准确率略保守于 TIS/IS。
